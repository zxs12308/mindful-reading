## 内容说明

本仓库收录的书目为传统文化中关于身心养护与自律的公益读物。其中既有收集自公开网络论坛的案例汇编，也有系统性讲解戒色方法的文章，另收录多部清代及以前的传统善书经典（如《寿康宝鉴》《欲海慈航》《欲海回狂》《安士全书》等），体现劝善、节欲、修身的传统思想。请理性看待书中观点，作为个人阅读参考即可，不构成医疗、心理或其他专业建议；如确有身心方面的困扰，请寻求正规专业帮助。
